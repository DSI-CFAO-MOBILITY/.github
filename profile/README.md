Nous concevons des applications adaptées aux besoins des différents départements de CFAO Mobility, en choisissant les technologies les mieux adaptées à chaque projet.

Nos principaux outils sont **PHP avec Symfony** et **Python**, ainsi que d’autres technologies selon les besoins.
